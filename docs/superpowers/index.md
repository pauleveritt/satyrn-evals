# Development record

Every feature cycle in this project produces a design spec and an
implementation plan, both committed rather than thrown away, so you can
read why the code looks the way it does — including the arguments that
were considered and rejected.

The roadmap of phases is `ROADMAP.md`; the specs, plans, and research
records live below, and the hidden toctrees below return here as each
phase completes. The V1 cycle's spec, plan, and review record are
committed under this directory.
