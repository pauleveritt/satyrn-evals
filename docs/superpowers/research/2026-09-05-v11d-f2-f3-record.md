## F2 — `had_patch` meant "a patch file exists", not "a patch"

Three sites, re-derived rather than restated:

- `pathology.py:321` gates `tool_free_terminal_turns` on `not had_patch`.
- `rescore.py` passed `had_patch=record.patch_path is not None`.
- `attempt_pi.py:230` writes `patch.diff` **unconditionally**.

So on every pi-adapter cell the field was recorded, the file existed, and
`had_patch` was `True` — the floored-model counter could not fire on the
refusals it was built to count.

**The fix** is `rescore._had_patch`, at the binder: a patch is a patch
when its file holds non-whitespace content. `count_transcript` keeps its
signature, so the pathology-level gate tests still pin the gate. A
recorded patch that cannot be read reports `True` and the counter stays
silent — absent evidence is not a finding (maintainer decision,
2026-09-05).

## F3 — reproduced, in both signal shapes

`run.py`'s abort path is `except BaseException` around the cell loop, and
a `UsageError` demonstrably reaches it. A signal does not: `except`
catches what Python *raises*, and the default disposition of SIGTERM and
SIGHUP raises nothing — the interpreter dies where it stands. From the
artifacts alone, an interrupted batch was then indistinguishable from one
that never started.

**F3 is not a misattribution.** `tests/integration/test_run_signal.py`
sends a real signal to a live `run` after cell 1 completes and while cell
2 is in flight. Against unfixed `run.py` both parametrizations failed at
`assert aborted.exists()` — "a signal-killed run wrote no abort record" —
while the clean-run sibling passed, so the missing record is the signal
and not the way the test drives `run`.

**The fix** is `run._abort_on_signals`: for the duration of the cell loop
SIGTERM and SIGHUP raise `SignalAbort` (a `BaseException`, so no inner
`except Exception` can swallow it), and the displaced handlers are
restored afterwards because `run` is a library call. SIGINT is untouched
— it already raises `KeyboardInterrupt`.

Acceptance, now green: the abort record exists and names the signal,
`requested: 3` / `completed: 1`, the completed cell keeps its
`attempt.json`, and the interrupted cell's directory has none — so the
two are distinguishable on disk.

### Stated limits

- **SIGKILL is outside this contract.** Nothing can catch it, so a
  `kill -9` batch still leaves no abort record.
- **The abort write is not itself signal-safe.** A second terminating
  signal arriving while the marker is being written can still truncate
  the round.
- **The child is not reaped.** A signal that kills `run` mid-cell leaves
  the attempt command running as an orphan; the test kills its own
  process group, and an operator must still check. Reaping is not in
  this slice.

### Test tier

Sending a signal to a live process needs a process, so this is
**integration-tier**, marked and excluded from CI. The planted-spawn
tripwire was **not** weakened: `tests/conftest.py` already opens the gate
on the `integration` marker, and that is the whole mechanism used here.
