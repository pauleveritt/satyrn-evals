## Review Focus

These are the inputs most likely to break the fix that no ruling names. Each one has a test in Task 1.
1. **A model that commits on a branch it created** (`git switch -c x`). The branch ref is written into the user's source repository, because a linked worktree shares refs. This must still be refused as `COMMAND_CHANGED_HEAD` and must never become a candidate. The existing integration test `test_attached_head_at_base_is_discarded_without_candidate` covers it and must stay green.
2. **A model that commits and then deletes the committed file from the worktree.** The candidate is the worktree's tree, not HEAD's, so the deleted file is absent from the candidate.
3. **A model whose only act is an empty commit** (`git commit --allow-empty`). The tree equals the base tree, so the result is `NO_CHANGES`, with `head_moved: true` on the receipt.
4. **A model that commits several times.** The candidate commit's only parent is `base_commit`, and none of the model's commits are reachable from the candidate ref.
5. **Old receipts and other readers.** `head_moved` is a new key. The TypeScript parser (`packages/engine/orchestrator.ts:380-397`) ignores unknown keys, and so does the evals reader (`attempt_engine.candidate_commit`). The receipt `version` stays 1, and no pinned digest changes.

```python
def head_disposition(head: str, base_commit: str, attached: bool) -> Literal["at_base", "moved", "attached"]:
    """What the model's command did to the isolated worktree's HEAD.

    An attached HEAD means the command created or switched to a branch; a
    linked worktree shares refs with the source repository, so that branch
    now exists there, and the attempt is refused (COMMAND_CHANGED_HEAD). A
    detached HEAD that moved means the model ran `git commit`; the candidate
    is built from the worktree's tree with `base_commit` as its only parent,
    never from HEAD, so the commit is recorded on the receipt and tolerated
    (parity with the harness's Baseline harvest, which diffs from the base).
    """
    if attached:
        return "attached"
    return "at_base" if head == base_commit else "moved"
```
