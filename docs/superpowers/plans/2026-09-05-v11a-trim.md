# V11a-trim — contract rungs, generated engine contract, rung provenance

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:test-driven-development for every task. Steps use checkbox
> (`- [x]`) syntax for tracking.

**Goal:** A task manifest can carry an open `contracts: {rung: text}` map;
`--rung` selects which text the model sees; every new attempt record and
summary names the rung and the digest of the exact text; and the engine
contract is generated from the manifest rather than hand-authored.

**Spec:** `docs/superpowers/specs/2026-09-05-v11a-trim-contract-rungs-design.md`

**Tech Stack:** Python ≥3.14, stdlib only, dataclasses, `type` aliases,
`match`/`case`, walrus.
