# V11b-trim — the two-arm substrate

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:test-driven-development for every task. Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** Baseline and Engine exist as committed, pinned, executable arm
definitions; the Baseline adapter lives in-tree instead of a scratch
directory; and a strict tally refuses a malformed batch rather than
shrinking a denominator.

**Spec:** `docs/superpowers/specs/2026-09-05-v11b-trim-arm-substrate-design.md`

**Tech Stack:** Python ≥3.14, stdlib only, dataclasses, `type` aliases,
`match`/`case`, walrus.

## Global Constraints

- **No commits on `main`.** You are in a dedicated worktree on your own
  branch; commit there freely so it can be merged, but never touch `main`.
- **You own these paths and no others.** A sibling agent owns
  `manifest.py`, `attempt.py`, `attempt_record.py`, `run.py`, `cli.py`,
  `summary.py`, `rescore.py`, `engine_contract.py`, and every
  `tasks/*/manifest.json`. Do **not** edit those.
  - new `src/satyrn_evals/attempt_pi.py`, new `src/satyrn_evals/arms.py`
  - new `arms/baseline.json`, `arms/engine.json`
  - new `scripts/preflight.sh`, `scripts/interleave.py`, `scripts/tally.py`
  - `pyproject.toml` — **you own it**, for the console-script entry and
    nothing else
  - new `tests/test_arms.py`, `tests/test_attempt_pi.py`,
    `tests/test_tally.py`, `tests/test_interleave.py`,
    new `tests/integration/test_attempt_pi.py`
- Python ≥3.14 house style per `CLAUDE.md`: real return type annotations;
  `type` aliases; `match`/`case` for dispatch; `:=` for bind-and-test.
- Default tier: **no model, no network, no subprocess**. The planted spawn
  tripwire fails the build — never weaken it. The adapter's own subprocess
  behavior is tested in the **integration** tier against the existing
  `tests/integration/fake_pi_v4.py` fixture.
- **Every refusal test gets a sibling success test** (BRIEF rule 6).
- **Verify, don't assert** (BRIEF rule 1).
- Keep 100% statement + branch coverage for anything under
  `src/satyrn_evals`. Decide deliberately whether `scripts/` is inside
  `--cov=src/satyrn_evals` (it is not, by path) and say so in your report.
- `uv run pytest -q` green at the end of every task.

### Task 4: `attempt_pi.py` — the Baseline adapter

**Files:** new `src/satyrn_evals/attempt_pi.py`; `pyproject.toml` console
script; tests `tests/test_attempt_pi.py` (default) and
`tests/integration/test_attempt_pi.py`.

- [ ] **Failing tests first, default tier (pure functions only).**
      Refusals: argv construction with no `--model`; an empty
      `SATYRN_TASK_CONTRACT`; a missing `SATYRN_PATCH`. Successes: argv is
      constructed with `--model` as **separate tokens** (pi 0.84.4 rejects
      the equals form in print mode — that is what engine `75d4863` fixed,
      and the same trap applies here); the prompt is read from
      `SATYRN_TASK_CONTRACT`; `--tools` is joined as pi expects.
- [ ] **Implement.** `--model`, `--tools`; prompt from
      `SATYRN_TASK_CONTRACT`; tee the JSON stream to `SATYRN_TRANSCRIPT`;
      after `pi` exits, harvest `git diff HEAD` into `SATYRN_PATCH`.
      **The adapter takes no `--rung`** — the rung reaches it as the
      contract env var. Keep process handling in `adapter_process.py`'s
      shape.
- [ ] **Document the `git diff HEAD` limit in the module docstring**: it
      drops files created by `write`. `git add -A` is not the fix — it
      sweeps `uv run pytest` residue into the patch and trips the allowlist
      check.
- [ ] **Integration test:** the adapter against `tests/integration/fake_pi_v4.py`
      produces a patch and a transcript. Marked `integration`.
- [ ] **Verify:** `uv run pytest -q` and `uv run pytest -m integration -q`.
